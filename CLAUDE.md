# Neon

Before working on this project, read `AGENTS.md` in the repository root in
full. It is the canonical project charter, mission, environment description,
and working agreement for all agents — and an index to the implementation
notes in `docs/`.

`AGENTS.md` is deliberately short so it can be read every session. The detail
lives in `docs/voice.md`, `docs/wake.md`, `docs/eyes.md` and
`docs/machine.md`; read the one your task touches rather than all four, and
record new findings in the file they belong to.

Keep durable shared guidance in those files rather than duplicating it here.
