# Neon 0.4

**She dozes off again.** Since 0.3 she would stay awake indefinitely after a
conversation instead of drifting off after a few seconds of quiet.

The idle timer had a rule against falling asleep mid-thought — don't doze if
the server has said anything recently — and Gemini turns out to send a
keepalive about twice a second for as long as the microphone is streaming. By
that measure it had *always* just said something. The timer now waits on real
work (speech, transcription, reasoning, tool calls) rather than on traffic.
